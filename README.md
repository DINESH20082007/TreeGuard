# 🌳 TreeGuard

### AI-Powered Urban Tree Health & Emergency Monitoring Platform

TreeGuard is a real-world environmental technology platform designed to help communities, organizations, campuses, parks, and municipalities monitor urban trees, identify potential tree-health risks, report dangerous conditions, and coordinate inspections and emergency response.

TreeGuard combines **AI-assisted assessment, location intelligence, tree monitoring, emergency reporting, field inspections, recovery planning, and analytics** into one platform.

---

## 🌱 Why TreeGuard?

Urban trees provide shade, cleaner air, biodiversity, and environmental benefits. However, unhealthy, damaged, or fallen trees can create serious safety risks when problems are not identified and addressed quickly.

TreeGuard connects:

- 👤 Citizens
- 🧑‍🔧 Field Inspectors
- 🏢 Organization Administrators

so that tree-related problems can move from **report → assessment → inspection → action → completion**.

---

## 🚀 Key Features

### 🤖 AI-Powered Tree Assessment

Users can upload tree images and receive an AI-assisted assessment containing:

- Potential issues detected
- Health indicators
- Severity
- Confidence score
- Possible risk factors
- Recommended inspection
- Manual review recommendation

> AI results are presented as assessments and are not treated as official diagnoses.

---

### 🗺️ Interactive Tree Map

Explore monitored trees and reported incidents through a location-based map.

Tree status includes:

- 🟢 Healthy
- 🟡 Monitoring
- 🟠 At Risk
- 🔴 Emergency

Users can search and view:

- Tree ID
- Tree location
- Health status
- Risk level
- Last inspection
- Tree details

The platform is focused on **Coimbatore and nearby areas** for the current implementation.

---

### 🚨 Emergency Detection

TreeGuard supports emergency situations such as:

- Fallen trees
- Broken branches
- Severe storm damage
- Trunk damage
- Road/path obstruction
- Trees near infrastructure

AI-assisted emergency analysis can identify potential conditions and provide:

- Detection result
- Severity
- Confidence
- Detected conditions
- Location risk
- Recommended action

---

### 📋 Tree Reporting

Citizens can submit tree-related reports using a guided workflow:

1. Select report type
2. Upload/capture photos
3. Confirm location
4. Add description
5. Receive AI assessment
6. Review report
7. Submit

Users can then track the report through its lifecycle.
